# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Project Files

- `welcome.py`: Defines a welcome function that returns a greeting for different names.
- `toolbox.py`: Defines three functions to double numbers, check pass marks, and greet people.

## Reflection

The `greet()` function was the hardest to write because it uses a default parameter. I learned that a function can use a default greeting when no greeting is provided, or accept a different greeting when one is supplied.
